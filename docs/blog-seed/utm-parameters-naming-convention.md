UTM tags are easy to add and easy to get wrong. One person writes "Spring_Sale" and another writes "spring-sale," and your report shows two campaigns that should be one. A clear UTM parameters naming convention prevents that. This guide gives you simple rules, a template you can copy, and examples for Facebook posts.

If you are new to UTM tags, read our guide to [tracking Facebook post clicks with UTM links](/blog/track-facebook-post-clicks-with-utm-links) first. This article is the next step: how to name things so your reports stay clean as you grow.

## Why naming matters

Analytics tools read your UTM tags exactly as you type them. They do not know that "Facebook," "facebook," and "fb" mean the same place. Each spelling becomes its own line in the report.

Messy names cause real problems.

- **Split reports.** One campaign shows up as three, and each looks small.
- **Wasted time.** Someone has to add the lines together by hand.
- **Lost history.** You cannot compare this spring to last spring if the names changed.
- **Confusion on a team.** Nobody knows which name is the right one.

A convention is just a short list of rules everyone follows. It takes ten minutes to write and saves hours later.

## The rules

Keep them short enough that people actually follow them.

1. **Use lowercase only.** Capital letters create duplicates.
2. **Use hyphens between words.** Write black-friday, not Black Friday or black_friday.
3. **Use no spaces and no special characters.** They break links and reports.
4. **Keep names short and readable.** You should understand them in a year.
5. **Use the same source and medium every time.** For Facebook posts, that is facebook and social.
6. **Put a date or season in campaign names that repeat.** For example, spring-sale-2027.
7. **Never include personal information.** Anyone who sees the link can read the tags.
8. **Keep a list of names in use.** Add each new name to the list before you use it.

## The five tags and what to put in them

| Tag | Required | What to put in it | Example |
|---|---|---|---|
| utm_source | Yes | Where the click comes from | facebook |
| utm_medium | Yes | The kind of link | social |
| utm_campaign | Yes | The promotion or goal | spring-sale-2027 |
| utm_content | No | Which version of a link | video-post |
| utm_term | No | A keyword, mostly for paid search | (leave empty) |

Start with the first three. Add content when you want to compare two posts in one campaign.

## A template you can copy

Use this pattern for the campaign name and keep each part short.

| Part | Meaning | Example |
|---|---|---|
| Goal or offer | What the campaign is about | spring-sale |
| Period | Season, month, or year | 2027 |
| Full name | Goal, then period | spring-sale-2027 |

For the content tag, name the format or the post.

| Content value | Use it for |
|---|---|
| photo-post | A post with a photo |
| video-post | A post with a video |
| text-offer | A plain text offer |
| post-1, post-2 | Two versions of the same idea |

## Examples for Facebook posts

Here are complete links for a garden shop. The base address is only an example.

| Situation | Tagged link |
|---|---|
| Spring sale photo post | example.com/sale?utm_source=facebook&utm_medium=social&utm_campaign=spring-sale-2027&utm_content=photo-post |
| Spring sale video post | example.com/sale?utm_source=facebook&utm_medium=social&utm_campaign=spring-sale-2027&utm_content=video-post |
| Monthly newsletter sign-up | example.com/signup?utm_source=facebook&utm_medium=social&utm_campaign=newsletter-signup |
| Event announcement | example.com/event?utm_source=facebook&utm_medium=social&utm_campaign=open-day-2027 |

Notice that source and medium never change. Only the campaign and content change. That is the whole idea.

## Keep a shared list

A convention only works if people can see it. Make a small shared list with three columns.

| Campaign name | Start date | Notes |
|---|---|---|
| spring-sale-2027 | 2027-03-01 | Photo and video posts, ends March 31 |
| newsletter-signup | 2026-11-01 | Always on |
| open-day-2027 | 2027-05-10 | One event post and one reminder |

Before you use a new campaign name, check the list. If it is already there, reuse it exactly. If it is new, add it first. One person should own the list.

## Common mistakes

- **Changing names mid-campaign.** The report splits and you lose the thread.
- **Using capital letters.** "Facebook" and "facebook" are different lines.
- **Using underscores in some names and hyphens in others.** Pick one and stay with it.
- **Tagging links on your own website.** UTM tags are for links that bring people to your site.
- **Putting names or emails in tags.** They are visible to anyone with the link.
- **Forgetting to test.** Click the link before you publish.

## How to roll this out on a team

A naming convention fails when it lives only in one person's head. Rolling it out takes three small steps, and you can finish them in an afternoon.

First, write the rules on one page. Use the list in this article, and change anything that does not fit your business. Keep the page short enough that a new person can read it in two minutes.

Second, create the shared list of campaign names and put it where everyone already works, such as a shared document or a spreadsheet. Name one person as the owner. That person approves new names, fixes mistakes, and retires names that are no longer used. Without an owner, the list slowly becomes a second mess.

Third, change the habit, not just the document. Ask everyone to build links with the same builder, and to check the list before they invent a new name. When a mistake appears, fix it kindly and explain why it matters. People follow a convention when they understand that it saves them time.

## Reading your report with clean names

The payoff of all this tidiness is a report you can read at a glance. When every Facebook post uses the same source and medium, your analytics tool can group all of your Facebook visits in one line. Inside that line you can compare campaigns, and inside each campaign you can compare the content tags.

Start with the biggest question: which campaigns sent the most visitors? Then ask which of those visitors did something valuable, such as buying, booking, or signing up. A campaign with fewer visitors but more sign-ups may deserve more of your effort. Finally, compare content tags inside the best campaign to see whether photos, videos, or plain text worked better. Because the names are consistent, these comparisons take a minute instead of an hour, and you can trust that you are comparing like with like.

## Frequently asked questions

**Do I have to use hyphens?** No. Underscores work too. What matters is picking one style and using it everywhere.

**Should campaign names include the year?** For campaigns that repeat each year, yes. It keeps one year's results apart from the next.

**Can I change a name later?** You can, but old results will stay under the old name. Plan names carefully at the start.

**Do UTM tags change what visitors see?** The page looks the same. The tags only add information to the address.

**What if someone already used a different name?** Choose one name to keep, update the shared list, and use it from now on. Old results stay where they are.
